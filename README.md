# Night War — Production 2D

Mobile-first cinematic static site. 3D/WebGL/Three.js removed. Content is data-driven through `data/roles.json` and `data/scenarios.json`.

## Structure
- `index.html` — semantic page structure, clearly sectioned.
- `css/` — tokens, base, motion, components and sections.
- `js/main.js` — navigation, reveal motion, scenario/role rendering, envelope and sheet interaction.
- `data/` — editable scenario and role content.
- `assets/images/` — final WebP artwork slots.

The site intentionally has no runtime framework or unnecessary dependency.
